# Live-verification regression suite (68k) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap the 68k live-verification corpus (`test/68k-live-verification/`)
into a runnable, manifest-driven PASS/FAIL suite (`LiveVerify`), landing
infrastructure plus a fully-verified 5-entry proof-of-concept batch covering
every recipe shape (asm, c+dependency, bas, existing repro script, and
choreographed multi-process).

**Architecture:** A `LiveVerifyCore` library (manifest schema, pattern
matcher, OS-9 process runner, solo/choreography executors) plus a thin
`LiveVerify` executable, mirroring this package's existing
`RBFHammerCore`/`RBFHammer` split so the core logic is unit-testable without
the emulator. See the design doc,
`docs/superpowers/specs/2026-07-21-live-verification-suite-design.md`.

**Tech Stack:** Swift 5.9, Foundation (`JSONDecoder`, `Process`, `Regex`), no
new dependencies. Lives in the existing `test/` SwiftPM package.

## Global Constraints

- No new dependencies (project rule).
- `os9exec` must never be pointed at anything but a per-run scratch device —
  never write to `h0` (the system disk) or the shared `h1` image.
- Every manifest `expect` value used below was captured by actually running
  the file against the locally built `os9exec` during planning (not
  guessed) — see the verified transcripts inline in Task 8. Any *new*
  manifest entry added later must be authored the same way: run it, read
  the real transcript, then write the assertion.
- 68k only. No `--target` flag, no 6809 code path, no `RBFHammerCore`
  import — see the design doc's Non-goals.
- `make test` must stay 132/0 (or whatever the current count is) throughout
  — this plan only adds files/targets, never touches `OS9Tests` or existing
  `GNUmakefile` targets.
- Line endings: every source file staged into the OS-9 scratch device must
  be CR-terminated (`\n` → `\r`), never LF — OS-9 text tools silently
  misbehave on LF-terminated input. This applies to `.a`/`.c`/`.bas` files
  and to hand-built editor-command scripts alike.
- Transcript normalization: OS-9 line endings are CR+LF; `tr '\r' '\n'`-style
  single-character replacement turns each `\r\n` into a blank line. Always
  normalize pair-first: replace `"\r\n"` with `"\n"`, *then* replace any
  remaining lone `"\r"` with `"\n"`, before matching any expectation.

```swift
//
//  Manifest.swift
//  LiveVerifyCore
//
//  The manifest schema: one JSON file (test/live-verification-manifest.json)
//  is the single source of truth for every wrapped test, so the ~86-file
//  corpus is data, not ~86 duplicated shell scripts.
//
//  Generated by Claude Sonnet 5 (Anthropic) — collaborator: rdoggett
//  date: 07-21-2026
//

import Foundation

/// The top-level manifest file.
public struct Manifest: Codable {
    public let entries: [ManifestEntry]
}

/// Whether an entry runs one program alone, or choreographs several
/// (backgrounded, timed) processes against a shared file.
public enum Category: String, Codable {
    case solo
    case choreography
}

/// One file to build. `moduleName` is explicit (not derived from `file`)
/// because this corpus's psect/module names don't always match their
/// filename mechanically (`batch1-01.a`'s psect is `batch101`, dash
/// stripped) — deriving it would be a fragile guess where an explicit
/// field is exact.
public struct SourceFile: Codable {
    public let file: String
    public let moduleName: String
    /// Solo category only: the one source whose output actually gets run
    /// and checked against `expect`. Every other source in the same entry
    /// is a dependency built (and, for `.a`, `load`ed resident) but never
    /// itself the thing under test.
    public let primary: Bool
}

/// Choreography category only: one process launch in the scenario.
public struct Role: Codable {
    /// Must match a `SourceFile.moduleName` in the same entry.
    public let moduleName: String
    /// Real seconds to wait (via the host, not OS-9) before launching this
    /// role, measured from when the choreography started.
    public let delayBeforeStart: Double
    /// True to background this role in the OS-9 shell (`&`); a `false`
    /// role blocks until it exits before the next command is sent.
    public let background: Bool
}

/// A literal substring (`contains`) or a regular expression (`matches`)
/// checked against the run's normalized transcript. Exactly one of the two
/// must be set — `ManifestValidation` (Task 3) enforces this.
public struct Expectation: Codable {
    public let contains: String?
    public let matches: String?
}

/// One wrapped test.
public struct ManifestEntry: Codable {
    public let id: String
    public let category: Category
    public let sources: [SourceFile]
    /// Choreography category only.
    public let roles: [Role]?
    /// All entries must match (AND, not OR) for the entry to PASS.
    public let expect: [Expectation]
    /// Provenance: which doc row / dogfood report this test guards. Not
    /// used by any check — for a future reader tracing a failure back to
    /// the original finding.
    public let notes: String
}
```

```swift
//
//  Expectation+Matching.swift
//  LiveVerifyCore
//
//  Pattern matching against a run's transcript, and manifest self-checks
//  that need no emulator at all -- a typo'd oracle must fail loudly at
//  review time, not silently pass because it matches everything.
//
//  Generated by Claude Sonnet 5 (Anthropic) — collaborator: rdoggett
//  date: 07-21-2026
//

import Foundation

/// Collapses OS-9's CR+LF line endings to a single `\n`, pair-first so a
/// real `\r\n` doesn't become a blank line (naive `tr '\r' '\n'`-style
/// single-character replacement does exactly that). A lone `\r` with no
/// paired `\n` still normalizes, so it never survives into a pattern match
/// as a literal carriage return.
public func normalizeTranscript(_ raw: String) -> String {
    raw.replacingOccurrences(of: "\r\n", with: "\n")
       .replacingOccurrences(of: "\r", with: "\n")
}

/// Whether `expectation` holds against an already-`normalizeTranscript`'d
/// transcript.
public func matches(_ expectation: Expectation, in transcript: String) -> Bool {
    if let literal = expectation.contains {
        return transcript.contains(literal)
    }
    if let pattern = expectation.matches, let regex = try? Regex(pattern) {
        return transcript.contains(regex)
    }
    return false
}

/// True only if every expectation matches (AND, not OR) — a test with two
/// assertions must fail if either one doesn't hold.
public func evaluate(_ expectations: [Expectation], against transcript: String) -> Bool {
    expectations.allSatisfy { matches($0, in: transcript) }
}

/// A manifest defect caught before any emulator run.
public enum ManifestValidationError: Error, CustomStringConvertible {
    case emptyContainsPattern(entryID: String)
    case invalidRegex(entryID: String, pattern: String)
    case expectationWithNeitherField(entryID: String)
    case soloEntryWithNoPrimarySource(entryID: String)
    case choreographyEntryWithNoRoles(entryID: String)
    case roleWithNoMatchingSource(entryID: String, moduleName: String)

    public var description: String {
        switch self {
        case .emptyContainsPattern(let id):
            return "\(id): an `expect` entry has an empty `contains` pattern"
        case .invalidRegex(let id, let pattern):
            return "\(id): `matches` pattern is not valid regex: \(pattern)"
        case .expectationWithNeitherField(let id):
            return "\(id): an `expect` entry has neither `contains` nor `matches`"
        case .soloEntryWithNoPrimarySource(let id):
            return "\(id): solo entry has no source marked `primary: true`"
        case .choreographyEntryWithNoRoles(let id):
            return "\(id): choreography entry has no `roles`"
        case .roleWithNoMatchingSource(let id, let name):
            return "\(id): role names moduleName \"\(name)\" with no matching source"
        }
    }
}

/// Validates one manifest entry's internal consistency. No emulator
/// involved -- this is a fast pass over the manifest's own data.
public func validate(_ entry: ManifestEntry) throws {
    for expectation in entry.expect {
        if let literal = expectation.contains {
            if literal.isEmpty {
                throw ManifestValidationError.emptyContainsPattern(entryID: entry.id)
            }
        } else if let pattern = expectation.matches {
            guard (try? Regex(pattern)) != nil else {
                throw ManifestValidationError.invalidRegex(entryID: entry.id, pattern: pattern)
            }
        } else {
            throw ManifestValidationError.expectationWithNeitherField(entryID: entry.id)
        }
    }

    switch entry.category {
    case .solo:
        guard entry.sources.contains(where: { $0.primary }) else {
            throw ManifestValidationError.soloEntryWithNoPrimarySource(entryID: entry.id)
        }
    case .choreography:
        guard let roles = entry.roles, !roles.isEmpty else {
            throw ManifestValidationError.choreographyEntryWithNoRoles(entryID: entry.id)
        }
        let knownModules = Set(entry.sources.map(\.moduleName))
        for role in roles where !knownModules.contains(role.moduleName) {
            throw ManifestValidationError.roleWithNoMatchingSource(entryID: entry.id, moduleName: role.moduleName)
        }
    }
}
```

```swift
            .deletingLastPathComponent()  // LiveVerifyCoreTests/

    }

    func testRunsASingleImmediateCommand() throws {
```

```swift
//
//  OS9Runner.swift
//  LiveVerifyCore
//
//  Launches the locally-built os9exec, feeding it staged (optionally timed)
//  shell input and capturing the transcript. The timed-staging variant is
//  what test/68k-live-verification/pipe-abort-repro.sh already does via
//  host shell `sleep` between piped writes, translated to real Swift
//  delays between stdin-pipe writes -- needed for choreography category's
//  real backgrounding (Task 6), where OS9Tests' existing os9() helper
//  (which writes all input at once) can't time anything.
//
//  Generated by Claude Sonnet 5 (Anthropic) — collaborator: rdoggett
//  date: 07-21-2026
//

import Foundation

/// One chunk of shell input, sent after waiting `delay` real seconds from
/// the previous chunk (or from run start, for the first chunk).
public struct StagedInput {
    public let text: String
    public let delay: TimeInterval

    public init(text: String, delay: TimeInterval) {
        self.text = text
        self.delay = delay
    }
}

/// What one run produced.
public struct RunOutcome {
    public let transcript: String
    public let timedOut: Bool
}

/// Runs staged shell input against the locally built `os9exec`.
public struct OS9Runner {
    private let execURL: URL
    private let diskPath: String

    /// - Parameter repoRoot: directory containing `os9exec` and `h0`.
    public init(repoRoot: URL) throws {
        execURL = repoRoot.appendingPathComponent("os9exec")
        diskPath = repoRoot.appendingPathComponent("h0").path
        guard FileManager.default.isExecutableFile(atPath: execURL.path) else {
            throw CocoaError(.fileNoSuchFile)
        }
    }

    /// Runs `staged` against a fresh `os9exec -r /dd/CMDS/shell`, using
    /// `scratchDir` (a directory the caller creates and owns) as the `/h5`
    /// device. Every staged chunk after the last real one is followed by
    /// ESC (`\u{1B}`), matching `OS9Tests`' own end-of-input convention, so
    /// callers don't need to append it themselves.
    public func run(staged: [StagedInput], scratchDir: URL, timeout: TimeInterval) -> RunOutcome {
        let process = Process()
        process.executableURL = execURL
        process.arguments = ["-r", "shell"]
        process.environment = ["OS9DISK": diskPath, "OS9H5": scratchDir.path]
        process.currentDirectoryURL = scratchDir

        let stdinPipe = Pipe()
        let stdoutPipe = Pipe()
        let stderrPipe = Pipe()
        process.standardInput = stdinPipe
        process.standardOutput = stdoutPipe
        process.standardError = stderrPipe

        guard (try? process.run()) != nil else {
            return RunOutcome(transcript: "", timedOut: false)
        }

        var collected = Data()
        let collectQueue = DispatchQueue(label: "liveverify.os9runner.collect")
        let readGroup = DispatchGroup()
        readGroup.enter()
        DispatchQueue.global().async {
            let handle = stdoutPipe.fileHandleForReading
            while true {
                let chunk = handle.availableData
                if chunk.isEmpty { break }
                collectQueue.sync { collected.append(chunk) }
            }
            readGroup.leave()
        }
        DispatchQueue.global().async {
            _ = stderrPipe.fileHandleForReading.readDataToEndOfFile()
        }

        for chunk in staged {
            if chunk.delay > 0 { Thread.sleep(forTimeInterval: chunk.delay) }
            stdinPipe.fileHandleForWriting.write(Data(chunk.text.utf8))
        }
        stdinPipe.fileHandleForWriting.write(Data("\u{1B}\n".utf8))
        stdinPipe.fileHandleForWriting.closeFile()

        let timedOut = readGroup.wait(timeout: .now() + timeout) == .timedOut
        if timedOut {
            process.terminate()
        }
        process.waitUntilExit()
        while process.isRunning { Thread.sleep(forTimeInterval: 0.01) }

        let transcript = collectQueue.sync {
            String(decoding: collected, as: UTF8.self)
        }
        return RunOutcome(transcript: transcript, timedOut: timedOut)
    }
}
```

```swift
//
//  SoloExecutor.swift
//  LiveVerifyCore
//
//  Builds and runs one `category: .solo` manifest entry. Each SourceFile's
//  extension picks the recipe: .a assembles+links via r68/l68, .c compiles
//  via cc (with any .a dependency built and F$Load-resident first so a
//  bare-name os9fork()/F$Fork from the C program can find it), .bas is fed
//  to an interactive `basic` session as an editor script (raw piped source
//  text does NOT work -- see the design doc and dogfood-report-eoflock-
--  2026-07-18.md's own note that these were "PACKed and run standalone"),
//  and .sh executes the file directly, host-side, using its own exit code.
//
//  Toolchain paths, chx, and CR line endings all follow gotchas documented
--  in 68k/os9-68k-assembly.md and basic09/pack-and-runb.md -- see inline
//  comments at each divergence from the "obvious" invocation.
//
//  Generated by Claude Sonnet 5 (Anthropic) — collaborator: rdoggett
//  date: 07-21-2026
//

import Foundation

/// What running one entry produced.
public enum ExecutionResult {
    case pass
    case fail(String)        // preview of the transcript
    case buildFailed(String) // r68/l68/cc/basic reported a toolchain error
    case timedOut
}

public struct SoloExecutor {
    private let runner: OS9Runner
    private let corpusDir: URL

    /// - Parameters:
    ///   - runner: drives `os9exec`.
    ///   - corpusDir: directory holding the `.a`/`.c`/`.bas`/`.sh` source
    ///     files named in manifest entries (in production,
    ///     `test/68k-live-verification/`; in tests, the `Fixtures` bundle
    ///     resource).
    public init(runner: OS9Runner, corpusDir: URL) {
        self.runner = runner
        self.corpusDir = corpusDir
    }

    public func run(_ entry: ManifestEntry, scratchDir: URL, timeout: TimeInterval) -> ExecutionResult {
        guard let primary = entry.sources.first(where: { $0.primary }) else {
            return .fail("no primary source (should have been caught by validate())")
        }

        // `.sh` short-circuits entirely: it's already a complete, runnable
        // repro script with its own exit-code contract (0 = pass).
        if primary.file.hasSuffix(".sh") {
            return runShellScript(primary)
        }

        do {
            for source in entry.sources {
                try stage(source, into: scratchDir)
            }
        } catch {
            return .buildFailed("failed to stage fixtures into scratch: \(error)")
        }

        let staged = buildCommands(entry: entry, primary: primary, scratchDir: scratchDir)
        let outcome = runner.run(staged: staged, scratchDir: scratchDir, timeout: timeout)
        if outcome.timedOut { return .timedOut }

        let transcript = normalizeTranscript(outcome.transcript)
        if transcript.contains("error -") {
            return .buildFailed(preview(transcript))
        }
        if evaluate(entry.expect, against: transcript) {
            return .pass
        }
        return .fail(preview(transcript))
    }

    // MARK: - Staging

    /// Copies a source file into the scratch device, converting LF to CR
    /// -- OS-9 text tools silently misbehave on LF-terminated input.
    private func stage(_ source: SourceFile, into scratchDir: URL) throws {
        let hostPath = corpusDir.appendingPathComponent(source.file)
        let text = try String(contentsOf: hostPath, encoding: .utf8)
        let converted = text.replacingOccurrences(of: "\n", with: "\r")
        try Data(converted.utf8).write(to: scratchDir.appendingPathComponent(source.file))
    }

    private func runShellScript(_ source: SourceFile) -> ExecutionResult {
        let scriptPath = corpusDir.appendingPathComponent(source.file).path
        let process = Process()
        process.executableURL = URL(fileURLWithPath: "/bin/sh")
        process.arguments = [scriptPath]
        let pipe = Pipe()
        process.standardOutput = pipe
        process.standardError = pipe
        guard (try? process.run()) != nil else {
            return .buildFailed("could not launch \(source.file)")
        }
        let output = String(decoding: pipe.fileHandleForReading.readDataToEndOfFile(), as: UTF8.self)
        process.waitUntilExit()
        return process.terminationStatus == 0 ? .pass : .fail(preview(output))
    }

    // MARK: - Command building

    /// Builds the full staged command list for a non-`.sh` entry: every
    /// dependency source first (assembled/linked/`load`ed, never run
    /// directly), then the primary source's own build-and-run recipe.
    private func buildCommands(entry: ManifestEntry, primary: SourceFile,
                               scratchDir: URL) -> [StagedInput] {
        var lines: [String] = []
        let scratch = scratchDir.path

        for source in entry.sources where !source.primary {
            lines += buildOnlyCommands(source, scratch: scratch)
        }

        switch fileKind(of: primary.file) {
        case .asm:
            lines += [
                "load /dd/CMDS/r68 /dd/CMDS/l68",
                "r68 -O=\(scratch)/\(primary.moduleName).r \(scratch)/\(primary.file)",
                "l68 -o=\(scratch)/\(primary.moduleName) \(scratch)/\(primary.moduleName).r",
                "\(scratch)/\(primary.moduleName)",
            ]
        case .c:
            lines += [
                "load /dd/CMDS/cpp /dd/CMDS/c68 /dd/CMDS/o68 /dd/CMDS/r68 /dd/CMDS/l68",
                "setenv CLIB /dd/LIB",
                "setenv CDEF /dd/DEFS",
                "cc \(scratch)/\(primary.file) -F=\(scratch)/\(primary.moduleName)",
                // Verified live: a bare-name os9fork()/F$Fork from this
                // program resolves via CHX, the same convention Shell
                // itself uses -- NOT via prior F$Load residency. CHX must
                // point at the scratch dir only for THIS final run step;
                // `cc`'s own bare-name tool resolution above already
                // happened against the default CHX (/dd/CMDS), so
                // switching now doesn't disturb it.
                "chx \(scratch)",
                "\(scratch)/\(primary.moduleName)",
            ]
        case .bas:
            // No current manifest entry combines a .bas primary with a
            // dependency, but `lines` (any dependency-build commands
            // accumulated above) must still be included, not discarded.
            // `chd` matters here: the corpus's .bas files open their data
            // files by bare relative name (e.g. "dlk.dat"), which resolves
            // against the DATA directory, not CHX.
            lines += ["mount -r=200 /liveverify9", "chd /liveverify9", "load math"]
            // `e <name>` etc. are BASIC09 editor commands, not shell
            // commands -- they only mean anything once `basic` is already
            // running and reading them as its own input. Verified live:
            // writing the script to a file and redirecting it as `basic`'s
            // stdin (`basic <path`) is what actually runs it; piping the
            // same text as top-level shell commands does nothing useful.
            let editorText = editorRunScript(primary, scratch: scratch)
            try? Data(editorText.utf8).write(to: scratchDir.appendingPathComponent("runscript"))
            lines.append("basic <\(scratch)/runscript")
            return [StagedInput(text: lines.joined(separator: "\n") + "\n", delay: 0)]
        }

        return [StagedInput(text: lines.joined(separator: "\n") + "\n", delay: 0)]
    }

    /// Dependency (`primary: false`) sources are built but never run
    /// directly: only `.a` dependencies are supported (the corpus has no
    /// `.c`/`.bas` dependency case). Assembled and linked to a file in the
    /// scratch dir named `moduleName`; that alone is enough for the
    /// primary's bare-name fork to find it once CHX points there (see the
    /// `.c` case above) -- no separate `load` step is needed or was tested.
    private func buildOnlyCommands(_ source: SourceFile, scratch: String) -> [String] {
        [
            "load /dd/CMDS/r68 /dd/CMDS/l68",
            "r68 -O=\(scratch)/\(source.moduleName).r \(scratch)/\(source.file)",
            "l68 -o=\(scratch)/\(source.moduleName) \(scratch)/\(source.moduleName).r",
        ]
    }

    /// A `.bas` solo entry is NOT run by piping its raw source text to
    /// `basic` -- that types e.g. `PROCEDURE eofdlk` at the interactive
    /// `Ready` prompt, which enters line-numbered edit mode rather than
    /// running anything, and the session spins forever once stdin runs dry
    /// (the same EOF-spin class of bug documented for BASIC09's debugger).
    /// The working shape, confirmed live: `e <name>`, each body line
    /// prefixed with a space (a bare command with no leading space is read
    /// as an editor command, not inserted text), `q` to leave edit mode,
    /// `run <name>`, `bye`.
    private func editorRunScript(_ source: SourceFile, scratch: String) -> String {
        var lines = ["e \(source.moduleName)"]
        // The body is staged into the scratch dir as source.file, but for
        // the editor we need its BASIC09 text with the `PROCEDURE <name>`
        // header stripped (`e <name>` synthesizes that header itself).
        let hostPath = corpusDir.appendingPathComponent(source.file)
        let text = (try? String(contentsOf: hostPath, encoding: .utf8)) ?? ""
        var body = text.split(separator: "\n", omittingEmptySubsequences: false).map(String.init)
        if body.first?.hasPrefix("PROCEDURE ") == true { body.removeFirst() }
        while body.last == "" { body.removeLast() }
        lines += body.map { " \($0)" }
        lines.append("q")
        lines.append("run \(source.moduleName)")
        lines.append("bye")
        return lines.joined(separator: "\r") + "\r"
    }

    private enum FileKind { case asm, c, bas }

    private func fileKind(of filename: String) -> FileKind {
        if filename.hasSuffix(".a") { return .asm }
        if filename.hasSuffix(".c") { return .c }
        return .bas
    }

    private func preview(_ transcript: String) -> String {
        transcript.split(separator: "\n")
            .filter { !$0.hasPrefix("#") && $0 != "$" && !$0.isEmpty }
            .prefix(6).joined(separator: " | ")
    }
}
```

```swift
//
//  ChoreographyExecutor.swift
//  LiveVerifyCore
//
//  Runs a `category: .choreography` entry: every source is a BASIC09
//  procedure, PACKed to a standalone module (not run via the raw-source
//  editor-run recipe SoloExecutor uses for solo .bas), then driven by
//  `roles` -- some backgrounded, some blocking, each after a real delay --
//  against one shared transcript.
//
//  Two PACK-specific gotchas this recipe routes around (both already
//  documented in basic09/pack-and-runb.md, confirmed live during this
//  suite's design):
//    1. `PACK name >target` prints a spurious Error #000:043/#051 even
//       when the output file is complete and correct -- never treated as
//       a build failure here.
//    2. A packed module can ONLY be invoked by bare name after `load`ing
//       it resident -- invoking it by explicit path (`/h5/lostinit`)
//       fails with the same #000:043, and a bare `lostinit` (without
//       `runb`) fails E$MNF. The working shape is `load <path>` once,
//       then `runb <moduleName>` (never a path) for every role launch.
//
//  Generated by Claude Sonnet 5 (Anthropic) — collaborator: rdoggett
//  date: 07-21-2026
//

import Foundation

public struct ChoreographyExecutor {
    private let runner: OS9Runner
    private let corpusDir: URL

    public init(runner: OS9Runner, corpusDir: URL) {
        self.runner = runner
        self.corpusDir = corpusDir
    }

    public func run(_ entry: ManifestEntry, scratchDir: URL, timeout: TimeInterval) -> ExecutionResult {
        guard let roles = entry.roles, !roles.isEmpty else {
            return .fail("no roles (should have been caught by validate())")
        }
        let scratch = scratchDir.path

        // Unlike SoloExecutor, no separate on-disk staging step is needed:
        // `editorPackScriptBody` reads each source's content directly and
        // builds a CR-joined editor script from it, so there is no
        // intermediate CR-converted file any command below needs to read.
        //
        // Every source's pack script is one continuous BASIC09 editor
        // session (matches how the original dogfood pass packed all three
        // lostupdate procedures together): concatenate their CR-joined
        // texts, `bye` once at the very end.
        let editorSession = entry.sources
            .map { editorPackScriptBody($0, scratch: scratch) }
            .joined() + "bye\r"

        // Stage 1: mount + pack everything (immediate).
        var staged: [StagedInput] = [
            StagedInput(text: writePackScriptAndBuildFirstStage(editorSession: editorSession,
                                                                scratch: scratch,
                                                                scratchDir: scratchDir,
                                                                entry: entry), delay: 0),
        ]

        // Stage 2+: one StagedInput per role, in the order given, honoring
        // each role's own delay and background flag.
        for role in roles {
            let command = role.background ? "runb \(role.moduleName) &\n" : "runb \(role.moduleName)\n"
            staged.append(StagedInput(text: command, delay: role.delayBeforeStart))
        }

        let outcome = runner.run(staged: staged, scratchDir: scratchDir, timeout: timeout)
        if outcome.timedOut { return .timedOut }
        let transcript = normalizeTranscript(outcome.transcript)
        if evaluate(entry.expect, against: transcript) {
            return .pass
        }
        return .fail(preview(transcript))
    }

    /// The corpus's choreography sources hardcode a real path under the
    /// shared, project-forbidden `/h1` image (`/h1/CLAUDETEST/...`, from
    /// the original dogfood pass). This suite must never touch that image
    /// -- every such path is redirected to this executor's own per-run RAM
    /// disk instead. Verified live against the lostupdate trio with this
    /// exact substitution (`/liveverify9` in place of `/h1/CLAUDETEST`).
    private static let sharedDiskPrefix = "/h1/CLAUDETEST"
    private static let scratchDiskDevice = "/liveverify9"

    /// `e <name>` / body (space-prefixed) / `q` / `pack <name> >path` for
    /// one source -- everything except the session-final `bye`, which is
    /// appended once after every source (see `run(_:scratchDir:timeout:)`).
    private func editorPackScriptBody(_ source: SourceFile, scratch: String) -> String {
        let hostPath = corpusDir.appendingPathComponent(source.file)
        let text = (try? String(contentsOf: hostPath, encoding: .utf8)) ?? ""
        var body = text.split(separator: "\n", omittingEmptySubsequences: false).map(String.init)
        if body.first?.hasPrefix("PROCEDURE ") == true { body.removeFirst() }
        while body.last == "" { body.removeLast() }
        body = body.map { $0.replacingOccurrences(of: Self.sharedDiskPrefix, with: Self.scratchDiskDevice) }
        var lines = ["e \(source.moduleName)"]
        lines += body.map { " \($0)" }
        lines.append("q")
        lines.append("pack \(source.moduleName) >\(scratch)/\(source.moduleName)")
        return lines.joined(separator: "\r") + "\r"
    }

    /// Writes the combined pack session to `<scratch>/packscript`, then
    /// returns the first-stage command text: feed that script to `basic`,
    /// `load` every produced module resident (required -- see the type doc
    /// comment on the invoke-by-bare-name-only gotcha; verified live that
    /// omitting this step, relying on PACK's own registration alone,
    /// produces wrong results), and `chd` to the scratch RAM disk so any
    /// role that opens a file by bare relative name resolves there.
    private func writePackScriptAndBuildFirstStage(editorSession: String, scratch: String,
                                                   scratchDir: URL, entry: ManifestEntry) -> String {
        try? Data(editorSession.utf8).write(to: scratchDir.appendingPathComponent("packscript"))
        var lines = ["mount -r=200 \(Self.scratchDiskDevice)", "load math", "basic <\(scratch)/packscript"]
        for source in entry.sources {
            lines.append("load \(scratch)/\(source.moduleName)")
        }
        lines.append("chd \(Self.scratchDiskDevice)")
        return lines.joined(separator: "\n") + "\n"
    }

    private func preview(_ transcript: String) -> String {
        transcript.split(separator: "\n")
            .filter { !$0.hasPrefix("#") && $0 != "$" && !$0.isEmpty }
            .prefix(6).joined(separator: " | ")
    }
}
```
